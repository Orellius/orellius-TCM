# Telegram Channel Manager (Archived)

> Telegram OSINT monitoring and content pipeline platform.

## What This Was

A high-performance OSINT Telegram monitoring and automation platform for sensitive intelligence environments. Scraped source channels, translated and analyzed content using local LLMs (Ollama), presented messages for human review via a LangGraph agent pipeline, and published approved content to target channels. Included real-time HFC rocket alert monitoring, stealth ghost monitoring, watermark removal, and enterprise RBAC.

## Stack

- **Desktop App** - Tauri 2.x (Rust)
- **Frontend** - React 19, Vite, TypeScript, Tailwind CSS v4, Zustand
- **Backend** - FastAPI (Python 3.12)
- **Orchestration** - LangGraph agent pipeline
- **LLM** - Ollama (local inference)
- **Database** - PostgreSQL 16, Redis 7, Qdrant
- **Telegram** - Telethon (MTProto)
- **Infra** - Docker Compose
